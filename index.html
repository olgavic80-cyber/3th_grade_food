Task 6. Remember the rule some/any!

Тип предложенияКакое слово?ПримерПеревод
Утверждение (+) some I have got some milk. У меня есть немного молока.
Отрицание (-) any I haven't got any milk. У меня совсем нет молока.
Вопрос (?) any Have you got any milk? У тебя есть молоко?
Вежливая просьба some (исключение!) Can I have some milk, please? Можно мне немного молока, пожалуйста?
